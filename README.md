## 🎯 What It Does

Upload any room photo and let **Google Gemini's multi-modal AI** instantly redesign it across multiple interior design styles — from Scandinavian minimalist to Industrial loft.

---

## ✨ Features

| Feature | Description |
|---|---|
| 📸 **Photo Upload** | Upload any room image for instant redesign |
| 🎨 **Multiple Styles** | Scandinavian, Modern, Bohemian, Industrial, and more |
| ⚡ **Instant Results** | Gemini API delivers redesigned renders in seconds |
| 🖼️ **Before/After** | Side-by-side comparison of original vs redesigned |

## ⚡ Quick Start

### Prerequisites
- Node.js 18+
- Google Gemini API key (free at [ai.google.dev](https://ai.google.dev))

```bash
# Clone
git clone https://github.com/Vijaykrishna2334/AI-Interior.git
cd AI-Interior

# Install
npm install

# Add your API key
echo "GEMINI_API_KEY=your_key_here" > .env.local

# Run
npm run dev
```
